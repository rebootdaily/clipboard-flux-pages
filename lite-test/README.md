# Field Lite TEST

Practice copy of the Field Lite rework (pull request #14) for trying on the iPad. It uses its own
storage (`fieldlite-test`) and offline cache, so it never touches real inspections in `lite/`.
Removed when pull request #14 is merged.

It also carries the eraser modes, forgiving circles, finger-on-a-box fix and first-open updates from pull
request #15, so they can be tried on the iPad before #14 and #15 are merged. Its version number shows at the
bottom of the home screen.
